Set up Hermes

✓
When the hermes CLI is on PATH, clicking Launch Command Center → on the last step configures all of this automatically — MCP tools, main model, and every agent's profile. The steps below are only for when that isn't possible (CLI missing, or you'd rather do it by hand).
  1. Install Hermes Desktop from hermes-agent.nousresearch.com and launch it — you'll land on "Let's get you setup with Hermes Agent", its model-provider picker.
  2. Pick a provider on that screen based on what you chose above:
    • Local models: that screen doesn't offer a local/Ollama option — click "I'll choose a provider later" at the bottom, then come back here and click Generate Integration Files. Dispatch's automatic setup (or the checklist below) points Hermes at Ollama for you.
    • Frontier models: match the provider you set above to its entry on that screen — Anthropic API Key, ChatGPT or Codex Subscription, xAI Grok, MiniMax, or Nous Portal cover the ones Dispatch supports. Paste the same key you entered above when it prompts.
    • Hybrid: click "I'll choose a provider later" — the local model is the default, and you'll set frontier overrides per-agent from the checklist below.
  3. Come back here and click Generate Integration Files below.
  4. Open ~/.hermes/config.yaml in a text editor and paste in the generated mcp_servers block from hermes-mcp.yaml.
  5. Restart Hermes.
  6. Work through the agent setup checklist below to create every role Hermes doesn't already have.
  1. Click Backup Existing Hermes Config first — always keep a copy of a working config before touching it.
  2. Click Generate Integration Files to produce a candidate mcp_servers block sized to this Mac.
  3. Open ~/.hermes/config.yaml and check whether it already has an mcp_servers: section — the status below tells you which case you're in.
    • No existing section: paste the generated block in as-is.
    • Existing section: merge server entries one at a time so you don't clobber servers you already rely on.
  4. To change your main model or add a provider, run hermes model in a terminal (or use Hermes Desktop's Settings → Model) rather than the first-run picker — that screen only appears once, on a fresh profile.
  5. Restart Hermes and confirm the new MCP servers show up in its tool list.
  6. Use the agent setup checklist below for any role Hermes doesn't already have.
